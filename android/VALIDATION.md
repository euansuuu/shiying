# Android 0.1.4 历史验证记录

日期：2026-10-23。安卓实现位于独立的 `android/`，本轮未修改桌面端。

## 本轮问题与结论

用户提供短链 `https://v.douyin.com/gZRVMkUc_H8/`。0.1.3 在 PGEM10 / Android 16 上两次复现前台约 60 秒解析超时。页面已加载完成，但没有解析结果。对应作品 ID 为 `7699797994765356298`。

根因：原流程把官方手机分享跳转转换为无分享参数的桌面作品页，样例的桌面数据返回 `aweme=null`。手机分享页去掉参数时也不提供 videoInfoRes；保留原短链重定向参数后，无需登录即可取得目标作品。进一步对照验证，官方分享页只携带 `from_ssr=1` 也能取得完整视频信息。正式实现保留视频分享跳转和参数，使用手机浏览器 UA，直链转换到同作品的官方手机 SSR 分享页。

附带缺陷：流式文本记录使用 UTF-8 字节长度，文本后可能直接跟 JSON 记录，原换行拆分会漏读。回归测试先失败再通过，修复后跳过文本记录的确切字节数，不接受文本中的伪记录。
